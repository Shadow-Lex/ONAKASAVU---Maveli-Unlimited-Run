# ONAKASAVU - Maveli Unlimited Run
Every year during Onam, **King Mahabali (Maveli)** visits his beloved people in Kerala. In **Maveli Run: Onam Ascent**, guide King Mahabali as he ascends the sacred temple staircase. Dodge rolling coconuts hurtling down the steps, leap over barriers, collect sacred golden umbrellas, and see how far up the staircase you can climb!
